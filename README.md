# บัญชีร้านป้าย

เว็บบันทึกรายรับรายจ่ายสำหรับร้านป้าย (งานต่อลูกค้า มัดจำ ยอดค้าง ต้นทุนต่องาน รายจ่ายร้าน สรุปรายเดือน)

- หน้าเว็บ: `index.html` (ไฟล์เดียว) ตั้งค่าที่ `config.js`
- ฐานข้อมูลและล็อกอิน: Supabase ตั้งค่าด้วย `supabase-setup.sql`
- โฮสต์: GitHub Pages
- `config.js` เก็บเฉพาะ Project URL และ publishable key ซึ่งเปิดเผยได้ ความปลอดภัยของข้อมูลมาจากล็อกอินและ Row Level Security ห้ามใส่ service_role key หรือรหัสผ่านในรีโป
